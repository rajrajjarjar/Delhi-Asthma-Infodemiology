1. EXECUTIVE SUMMARY & RESEARCH OBJECTIVE
--------------------------------------------------------------------------------
Phase 2 (Spearman Rank Lag Correlation) confirmed that symptom search queries 
strongly correlate with laboratory-confirmed influenza (rho = 0.77 to 0.80 
during epidemic waves).

However, correlation alone does not establish causality or temporal precedence. 
A common criticism in infodemiology is that search volume might be a "reactionary 
artifact"—i.e., people search because the media is reporting high case numbers, 
rather than searching because they are experiencing early onset symptoms.

Phase 3 implements Granger Causality to rigorously answer:
  "Does past Google Trends search volume provide statistically significant 
   predictive information about future laboratory-confirmed flu cases beyond 
   what the flu series' own historical trajectory provides?"

Summary of Findings:
  1. Econometric Validity: Both WHO FluNet cases and Google Trends search indices 
     are verified stationary via the Augmented Dickey-Fuller (ADF) test (p < 0.001), 
     satisfying the prerequisite for Vector Autoregression (VAR) estimation.
  2. True Unidirectional Sentinels (The Gold Standard):
     - Delhi (IN-DL): Forward causality is overwhelmingly significant 
       (F = 19.713, p = 2.37 x 10^-20 across all 8 lag weeks). Crucially, the 
       reverse test (Flu -> GT) is completely non-significant (p = 0.222). 
       This provides definitive econometric proof of early-warning behavior.
     - Tamil Nadu (IN-TN): Unidirectional forward causality (F = 8.675, p = 0.0034; 
       reverse p = 0.059 n.s.).
     - Kerala (IN-KL): Unidirectional forward causality (F = 4.986, p = 0.0261; 
       reverse p = 0.105 n.s.).
  3. Dominant Transmission Incubators:
     - Maharashtra (IN-MH): Extremely strong forward causality (F = 19.606, 
       p = 6.09 x 10^-12 across all 8 lag weeks), peaking at lag 3 (3-week lead). 
       This persistence holds true even in the post-COVID recovery period 
       (F = 12.073, p = 6.24 x 10^-4).
  4. National Macro Feedback:
     - The National baseline exhibits a bidirectional feedback loop (both forward 
       and reverse p < 10^-6), confirming that macro search volume nowcasts cases 
       while high national caseloads drive public information-seeking.

2. ECONOMETRIC FRAMEWORK & MATHEMATICAL FORMULATION
================================================================================
A. Vector Autoregression (VAR) Formulation:
   Granger causality is evaluated by comparing two autoregressive models:

   Restricted Model (Autoregressive baseline of Flu cases):
     Flu_t = alpha + sum_{i=1}^p [ gamma_i * Flu_{t-i} ] + epsilon_t

   Unrestricted Model (Bivariate model incorporating past Google Trends):
     Flu_t = alpha + sum_{i=1}^p [ gamma_i * Flu_{t-i} ] + sum_{j=1}^p [ beta_j * GT_{t-j} ] + u_t

   Hypothesis Test:
     Null Hypothesis (H0): beta_1 = beta_2 = ... = beta_p = 0
     (Past Google Trends search values do NOT Granger-cause Flu cases).

   Test Statistic:
     F = [ (SSR_restricted - SSR_unrestricted) / p ] / [ SSR_unrestricted / (T - 2p - 1) ]
     where SSR is the Sum of Squared Residuals, p is the lag order, and T is sample size.
     Under H0, F follows an F-distribution with (p, T - 2p - 1) degrees of freedom.

B. Bidirectional Hypothesis Matrix:
   To prove that an indicator is predictive rather than reactive, tests must be 
   conducted in both directions:
   -----------------------------------------------------------------------------
   Forward Test (GT -> Flu)   Reverse Control (Flu -> GT)   Classification
   -----------------------------------------------------------------------------
   Significant (p < 0.05)     Non-Significant (p > 0.05)    TRUE UNIDIRECTIONAL SENTINEL
   Significant (p < 0.05)     Significant (p < 0.05)        BIDIRECTIONAL FEEDBACK LOOP
   Non-Significant (p > 0.05) Significant (p < 0.05)        REACTIVE / NEWS-DRIVEN
   Non-Significant (p > 0.05) Non-Significant (p > 0.05)    NO RELATIONSHIP
   -----------------------------------------------------------------------------

3. STATIONARITY TESTING (AUGMENTED DICKEY-FULLER TESTS)
================================================================================
Granger causality requires covariance-stationary time series to avoid spurious 
regression. The Augmented Dickey-Fuller (ADF) test evaluates:
  H0: Series has a unit root (non-stationary).
  H1: Series is stationary (reject H0 if p < 0.05).
